# [📈 État en direct](https://Mathos34.github.io/mlj-disponibilite): <!--live status--> **Tous les services fonctionnent**

Sonde de disponibilité de [MLJ Digital](https://www.mljdigital.fr), propulsée par [Upptime](https://github.com/upptime/upptime), sur le modèle de [milo-disponibilite](https://github.com/Mathos34/milo-disponibilite).

- Toutes les 5 minutes, GitHub Actions interroge, depuis l'extérieur de la VM OVH, le site (et sa base), MLJ Assistant (de bout en bout), l'Espace et le CRM.
- Une panne ouvre une [issue](https://github.com/Mathos34/mlj-disponibilite/issues) assignée : GitHub envoie un courriel. Le retour à la normale la ferme.
- Ce dépôt est public pour que les relevés ne coûtent aucune minute d'Actions ; il ne contient aucun secret.
- Configuration : `.upptimerc.yml` (ne pas modifier les workflows à la main, Upptime les génère).
